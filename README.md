## 🚀 What I'm building: Compounza

<img src="assets/compounza-mark.png" alt="Compounza" width="64" align="right">

**[compounza.in](https://compounza.in)** publishes books and portfolio projects for people building a career with data.

| | |
|---|---|
| 📘 **The Interview Readiness Book** | 1,226 data-science interview questions in 16 banks, each answered the way an interviewer scores it, in 863 pages |
| 📚 **Analyst to Architect** | Three volumes, 68 chapters, 2,997 pages: from "what is data?" to the work of a data architect |
| 🧩 **16 portfolio projects** | Excel, Python, machine learning and computer vision; each with a guide, real data, a worked solution and interview questions |

Behind it: a full-stack shop I built end to end, with **React** on Cloudflare Workers, a **FastAPI** server, **PostgreSQL**, secure stamped downloads, online payments, PDF invoices and an owner console.
